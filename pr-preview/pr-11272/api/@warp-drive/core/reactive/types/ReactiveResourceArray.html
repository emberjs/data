Defined in: warp-drive-packages/core/src/store/-private/record-arrays/resource-array.ts:122

A reactive Array of records, backed by a ResourceKey array in the cache. Returned by Store.request for collection responses and used as the base for relationship and legacy record-array types such as LegacyLiveArray, LegacyQueryArray and LegacyManyArray.

Behaves like a native Array: Array.isArray(arr) and arr instanceof Array both report true. The array stays in sync with the cache, updating reactively as the underlying ResourceKeys change.
