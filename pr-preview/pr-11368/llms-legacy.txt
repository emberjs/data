# WarpDrive Legacy Documentation

> Guides for legacy setups and API reference for `@warp-drive/legacy` (Models, Adapters, Serializers) and for the legacy `@ember-data/*` and early `@warp-drive/*` packages, kept for apps that have not yet migrated.

The modern documentation is indexed in https://canary.warp-drive.io/pr-preview/pr-11368/llms.txt. The full text of every page listed here is in https://canary.warp-drive.io/pr-preview/pr-11368/llms-legacy-full.txt.

## Guides

- [Setup - Legacy (Ember)](https://canary.warp-drive.io/pr-preview/pr-11368/guides/configuration/ember.md): Restore legacy Adapter, Serializer, Model, and EmberObject features through @warp-drive/legacy in an Ember app, and decide when LegacyNetworkHandler is still needed.
- [Overview](https://canary.warp-drive.io/pr-preview/pr-11368/guides/configuration/legacy-package-setup.md): Install the pre-unification @ember-data/* and @warp-drive/* packages with exact pinned versions, for apps still on the legacy multi-package setup rather than @warp-drive/core.
- [Ember.js](https://canary.warp-drive.io/pr-preview/pr-11368/guides/configuration/legacy-package-setup/setup/ember.md): Configure a legacy Ember app to import @warp-drive/ember/install, drop @ember-data/tracking, and add LegacyNetworkHandler plus adapterFor and serializerFor hooks to the store.
- [Setup](https://canary.warp-drive.io/pr-preview/pr-11368/guides/configuration/legacy-package-setup/setup/universal.md): Configure the legacy multi-package setup with setConfig in ember-cli-build, unstable-preview-types in tsconfig, and a hand-built Store using RequestManager and JSONAPICache.
- [Configuration](https://canary.warp-drive.io/pr-preview/pr-11368/guides/the-manual/typescript/configuration.md): Add the unstable-preview-types entries to tsconfig.json so your app consumes WarpDrive's alpha-stage native types from either the runtime packages or the -types packages.
- [Installation](https://canary.warp-drive.io/pr-preview/pr-11368/guides/the-manual/typescript/installation.md): Install WarpDrive's native types with `npx warp-drive retrofit types@canary` or by hand, replacing DefinitelyTyped @types packages with typed releases or -types packages.
- [Typing Models & Transforms](https://canary.warp-drive.io/pr-preview/pr-11368/guides/the-manual/typescript/typing-models.md): Brand legacy Model classes and Transforms with the `Type` symbol and add generics to `attr`, `belongsTo`, and `hasMany` so relationships and store calls infer types.
- [Using Codemods](https://canary.warp-drive.io/pr-preview/pr-11368/upgrading/v5/codemods.md): Run the `@ember-data/codemods` migrate-to-schema and legacy-compat-builders codemods to convert 4.x Models and mixins into 5.x schemas and store.request builders.
- [Incremental adoption guide for existing projects](https://canary.warp-drive.io/pr-preview/pr-11368/upgrading/v5/incremental-adoption.md): Move an existing 4.12 EmberData app still on adapters and serializers onto RequestManager, LegacyNetworkHandler, and request builders one step at a time.
- [Migrating 4.x to 5.x](https://canary.warp-drive.io/pr-preview/pr-11368/upgrading/v5.md): Migrate an EmberData 4.6 or 4.12 app to WarpDrive 5.x step by step, using native types, mirror packages, useLegacyStore, and schemas in place of Models.
- [Migrating Between Versions Using The Two Store Approach](https://canary.warp-drive.io/pr-preview/pr-11368/upgrading/v5/two-store-migration.md): Run a second WarpDrive store built from the -mirror packages beside your existing 4.x store so parts of an app can adopt 5.x incrementally, with the tradeoffs to expect.

## @warp-drive/legacy

- [@warp-drive/legacy](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy.md): Opt-in support for features deprecated out of `@warp-drive/core`, such as Models, Adapters, Serializers and legacy store APIs, for apps that still need to migrate away from them.
- [Adapter](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/adapter/classes/Adapter.md): Legacy abstract base class for adapters that translate store requests such as `findRecord` and `updateRecord` into calls against a persistence layer.
- [@warp-drive/legacy/adapter/error](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/adapter/error.md): Legacy adapter errors, such as `AdapterError`, `InvalidError` and `NotFoundError`, that an adapter returns or throws to signal a failed API request.
- [AbortError](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/adapter/error/types/AbortError.md): Legacy adapter error signaling that a request to the API was aborted before a response arrived.
- [AdapterError](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/adapter/error/types/AdapterError.md): Legacy base error an adapter returns or throws to signal a failed API request; extend it to define app-specific error types.
- [AdapterRequestError](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/adapter/error/types/AdapterRequestError.md): Legacy adapter error shape: an `Error` flagged `isAdapterError` with a `code` string and a {json:api} `errors` array, as thrown by `AdapterError` and its subclasses.
- [AdapterRequestErrorConstructor](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/adapter/error/types/AdapterRequestErrorConstructor.md): Static side of the legacy adapter error constructors: `new (errors?, message?)` plus `extend({ message })` for creating further error subclasses.
- [ConflictError](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/adapter/error/types/ConflictError.md): Legacy adapter error for an HTTP 409 response, signaling that the request conflicts with existing server state, such as a duplicate client-generated id.
- [ForbiddenError](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/adapter/error/types/ForbiddenError.md): Legacy adapter error for an HTTP 403 response, signaling that the server refused a valid request the user lacks permission for.
- [InvalidError](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/adapter/error/types/InvalidError.md): Instance type of the legacy `InvalidError`, the adapter error for a request the API rejected as semantically invalid.
- [NotFoundError](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/adapter/error/types/NotFoundError.md): Legacy adapter error for an HTTP 404 response, signaling that the requested resource does not exist on the API.
- [ServerError](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/adapter/error/types/ServerError.md): Legacy adapter error for an HTTP 500 response, signaling that the API failed internally and an immediate retry is unlikely to succeed.
- [TimeoutError](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/adapter/error/types/TimeoutError.md): Legacy adapter error signaling that a request to the API timed out without receiving a response.
- [UnauthorizedError](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/adapter/error/types/UnauthorizedError.md): Legacy adapter error for an HTTP 401 response, signaling that authorization is required and failed or was not provided.
- [AbortError](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/adapter/error/variables/AbortError.md): Legacy adapter error constructor for signaling that a request to the API was aborted before a response arrived.
- [AdapterError](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/adapter/error/variables/AdapterError.md): Legacy base error constructor an adapter uses to signal a failed API request; call `extend` on it to define app-specific error types.
- [ConflictError](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/adapter/error/variables/ConflictError.md): Legacy adapter error constructor for an HTTP 409 response, signaling that the request conflicts with existing server state, such as a duplicate client-generated id.
- [ForbiddenError](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/adapter/error/variables/ForbiddenError.md): Legacy adapter error constructor for an HTTP 403 response, signaling that the server refused a valid request the user lacks permission for.
- [InvalidError](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/adapter/error/variables/InvalidError.md): Legacy adapter error signaling that the API rejected a request as semantically invalid, typically failed server-side validation, putting the record in the `invalid` state.
- [NotFoundError](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/adapter/error/variables/NotFoundError.md): Legacy adapter error constructor for an HTTP 404 response, signaling that the requested resource does not exist on the API.
- [ServerError](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/adapter/error/variables/ServerError.md): Legacy adapter error constructor for an HTTP 500 response, signaling that the API failed internally and an immediate retry is unlikely to succeed.
- [TimeoutError](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/adapter/error/variables/TimeoutError.md): Legacy adapter error constructor for signaling that a request to the API timed out without receiving a response.
- [UnauthorizedError](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/adapter/error/variables/UnauthorizedError.md): Legacy adapter error constructor for an HTTP 401 response, signaling that authorization is required and failed or was not provided.
- [@warp-drive/legacy/adapter](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/adapter.md): Legacy adapter layer through which the store fetches and saves data from an API, superseded by `RequestManager` handlers.
- [JSONAPIAdapter](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/adapter/json-api/classes/JSONAPIAdapter.md): Legacy adapter that turns store requests into HTTP requests following JSON:API URL, verb, and `application/vnd.api+json` conventions.
- [@warp-drive/legacy/adapter/json-api](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/adapter/json-api.md): Legacy `JSONAPIAdapter`, which turns store requests into HTTP requests following JSON:API URL, verb and header conventions.
- [RESTAdapter](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/adapter/rest/classes/RESTAdapter.md): Legacy adapter that exchanges conventional REST-style JSON with an HTTP server, building URLs from model names and ids.
- [@warp-drive/legacy/adapter/rest](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/adapter/rest.md): Legacy `RESTAdapter`, which exchanges conventional REST-style JSON with an HTTP server, plus the request types it builds.
- [FetchRequestInit](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/adapter/rest/types/FetchRequestInit.md): `fetch` options plus `url`, `method`, and `type` that the legacy `RESTAdapter` builds for a request sent with the native `fetch` API.
- [JQueryRequestInit](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/adapter/rest/types/JQueryRequestInit.md): jQuery `$.ajax` settings plus `url`, `method`, and `type` that the legacy `RESTAdapter` builds when it sends a request through jQuery.
- [QueryState](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/adapter/rest/types/QueryState.md): Query params the legacy `RESTAdapter.buildQuery` adds to `findRecord` and `findAll` URLs, such as the `include` paths to sideload.
- [RequestData](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/adapter/rest/types/RequestData.md): The url and HTTP method of a legacy `RESTAdapter` request, used to build error messages when that request fails.
- [BuildURLMixin](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/adapter/types/BuildURLMixin.md): Legacy adapter mixin providing `buildURL` and the `urlFor*` hooks that turn a model name, id, snapshot, and request type into a request URL.
- [BuildURLMixin](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/adapter/variables/BuildURLMixin.md): Legacy `Mixin` that adds `buildURL` and the `urlFor*` hooks to an adapter so it can turn a model name, id, snapshot, and request type into a request URL.
- [ConfiguredStore](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/classes/ConfiguredStore.md)
- [findAll()](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/compat/builders/functions/findAll.md): Deprecated legacy builder for a `store.request` config that behaves like `store.findAll`, easing migration off adapters and serializers.
- [findRecord()](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/compat/builders/functions/findRecord.md): Deprecated legacy builder for a `store.request` config that behaves like `store.findRecord`, taking a type and id or a resource identifier.
- [query()](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/compat/builders/functions/query.md): Deprecated legacy builder for a `store.request` config that behaves like `store.query`, returning the records matching a query object.
- [queryRecord()](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/compat/builders/functions/queryRecord.md): Deprecated legacy builder for a `store.request` config that behaves like `store.queryRecord`, returning a single record or `null` for a query object.
- [saveRecord()](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/compat/builders/functions/saveRecord.md): Deprecated legacy builder for a `store.request` config that creates, updates, or deletes a record through adapters, like the legacy `store.saveRecord`.
- [@warp-drive/legacy/compat/builders](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/compat/builders.md): Deprecated request builders that move `findRecord`, `query`, and `saveRecord` calls to `store.request` while still using adapters and serializers.
- [@warp-drive/legacy/compat/extensions](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/compat/extensions.md): Legacy schema extensions that give reactive objects and arrays the classic `EmberObject` and Ember array APIs, such as `get`, `set` and `mapBy`, plus matching types.
- [ArrayType](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/compat/extensions/types/ArrayType.md): Type utility resolving to the element type of an array type, or `never` for non-arrays.
- [WithArrayLike](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/compat/extensions/types/WithArrayLike.md): Legacy type that adds Ember array methods such as `mapBy` and `firstObject` to a reactive array type using `EmberArrayLikeExtension`.
- [WithEmberObject](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/compat/extensions/types/WithEmberObject.md): Legacy type that adds the classic `EmberObject` methods to a reactive resource type using `EmberObjectExtension` or `EmberObjectArrayExtension`.
- [EmberArrayLikeExtension](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/compat/extensions/variables/EmberArrayLikeExtension.md): Legacy schema extension that gives reactive arrays Ember array methods such as `pushObject`, `mapBy`, `filterBy`, and `firstObject`.
- [EmberObjectArrayExtension](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/compat/extensions/variables/EmberObjectArrayExtension.md): Legacy schema extension that gives reactive arrays the classic `EmberObject` API such as `get`, `set`, and observers, to ease migration from Ember objects.
- [EmberObjectExtension](https://canary.warp-drive.io/pr-preview/pr-11368/api/@warp-drive/legacy/compat/extensions/variables/EmberObjectExtension.md): Legacy schema extension that gives reactive objects the classic `EmberObject` API such as `get`, `set`, and observers, to ease migration from Ember objects.
